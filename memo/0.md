# 型判定ライブラリ

```javascript
const typb = Typ.bool;
const typt = Typ.throw;
typB.as/of/some/not(); // return boolean
typT.as/of/some/not(); // throw new TypeError
```
```javascript
typX.getName(v); // 型名返却(string)
typX.as(v, '型名'); // return/throw
typX.of(v, a=>a.p.num); // return/throw
typX.some(v, a=>a.p, a=>a.r, ...); // return/throw(型のうちいずれか一つと一致すれば真を返す)ホワイトリスト
typX.not(v, a=>a.p, a=>a.r, ...); // return/throw(型のうち全てと一致しなければ真を返す)ブラックリスト
```
```javascript
typX.of(v, a=>a.r.ary); // 型補足引数なし
typX.of(v, a=>a.r.ary(Number)); // 型補足引数あり（任意）
typX.of(v, a=>a.p.num.int.range(0, 100)); // 型補足引数あり（必須）
```
```javascript
typX.of(new Boolean(), a=>...); // throw new TypeError BoxedPrimitiveは使用禁止
typX.of({constructor:null}, a=>...); // throw new TypeError 破綻オブジェクトは使用禁止
typX.of(Object.create(null), a=>a.r.dic); // true（Dictionary型（破綻オブジェクトでないと判断する））
```
