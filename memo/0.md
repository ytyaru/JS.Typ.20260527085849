# 型判定ライブラリ

```javascript
Typ.getName(v); // 型名返却(string)
Typ.as(v, '型名'); // 型名返却(string)
Typ.of(v, a=>a.p.num); // boolean返却
Typ.throw(v, a=>a.p.num); // throw new TypeError
```
```javascript
Typ.of(v, a=>a.r.ary); // 型補足引数なし
Typ.of(v, a=>a.r.ary(Number)); // 型補足引数あり（任意）
Typ.of(v, a=>a.p.num.int.range(0, 100)); // 型補足引数あり（必須）
```
```javascript
Typ.of(new Boolean(), a=>...); // throw new TypeError BoxedPrimitiveは使用禁止
Typ.of({constructor:null}, a=>...); // throw new TypeError 破綻オブジェクトは使用禁止
Typ.of(Object.create(null), a=>a.r.dic); // true（Dictionary型（破綻オブジェクトでないと判断する））
```
